Termos de uso

Última atualização: 22 de setembro de 2026.

1. Finalidade

O RailGuard é um sistema acadêmico destinado à gestão de operações ferroviárias, incluindo trens, rotas, cargas e manutenções.

2. Acesso

Cada pessoa deve utilizar sua própria conta. O acesso depende da aprovação do gestor e das permissões atribuídas ao cargo.

3. Responsabilidade

Os usuários devem registrar informações corretas e não compartilhar senhas. Ações realizadas no sistema podem ser registradas para segurança e auditoria.

4. Dados

Os dados cadastrados devem ser usados apenas para as atividades autorizadas do projeto. Senhas são armazenadas de forma protegida.

5. Disponibilidade

Por ser um projeto acadêmico, o serviço pode ficar temporariamente indisponível durante testes, manutenção ou atualização.

6. Aceitação

Ao utilizar o RailGuard, o usuário declara estar de acordo com estes termos. Este texto deve ser revisado pelos responsáveis pelo projeto antes da publicação.
